## 👋 About me

Full-Stack Developer at **WGB Soluções de Software** and Software Engineering student at **INATEL**. I build systems for municipal public management — including **UPEsporte**, a sports management platform already used by the city of Santa Rita do Sapucaí. I care about **clean code**, good practices, and meaningful collaboration.

- 💼 Building public-management systems with **Laravel**, **React**, **Next.js** and **Vue.js** at WGB
- 📱 Working with **React Native + Expo** and **NestJS** on personal and team projects
- 🧪 Practicing **TDD** with Jest — tests first, implementation after
- 🔄 Using **GitFlow**, Kanban, and code review through Pull Requests daily
- 🚀 Building automated **CI/CD pipelines** with GitHub Actions
