## About me

I'm a **Full-Stack Developer at [WGB Soluções de Software](https://wgbsolucoes.com.br/)** and a **Software Engineering** student at **Inatel**. I build ERPs for Brazilian city halls and SaaS products end to end, from the API to the web and mobile apps.

## Work — WGB Soluções de Software

> Private repositories.

**🏛️ UPGestão — ERP for city halls** · Laravel · Vue 3 · PostgreSQL
I own sign-in and access control (login, gov.br, user roles and permissions) and build the Urban Development module (public and private construction works, permits, occupancy certificates and service invoices for works) and the Social Assistance module.

**🧾 Portal do Contribuinte — taxpayer self-service portal** · Nuxt 4 · Vue 3 · TypeScript
Taxpayers issue invoices, register works, request permits and tax clearance certificates and link accountants and representatives. I built sign-in, the invite flow for accountants, legal representatives and attorneys, per-profile access control, and works registration and invoicing.

**🏟️ UPEsporte — sports management ERP** · Laravel · React · Next.js · Tailwind CSS
Admin panel and public portal for competitions, athletes, sports projects, students, coaches, equipment, venues, news and meeting minutes, in use by the City of Santa Rita do Sapucaí. Citizens create an account, register teams and book sports venues.

**🎬 Roncou — AI video engine for car dealers** · Laravel · Next.js *(in development)*
Connects the dealer's Instagram, Facebook, OLX and other channels and builds a briefing automatically to generate Reels, Stories, posts and YouTube videos. Google and Apple sign-in, admin panel, dealer landing pages and a WhatsApp integration to order, publish and track each video's results.

**💰 Meu Bolsim — personal finance assistant on WhatsApp** · Laravel · Next.js · Flutter
Built solo: Laravel API with queues, Next.js web panel and an iOS/Android app in Flutter. AI reads messages like "gastei 20 reais em gasolina" and categorizes the expense; the app flags upcoming bills, suggests paying upfront or in installments, tracks goals and builds spending reports.

## Featured projects

**🎯 [Retake](https://retake-gg.vercel.app)** · Next.js · TypeScript · PostgreSQL · Better Auth · Tailwind CSS · shadcn/ui
Social Valorant tracker: syncs matches from the HenrikDev API on the server (Zod validation and rate limiting), computes progress metrics and gathers friends in private groups with internal rankings. Google and Discord sign-in, tests with Vitest and Playwright, deployed on Vercel.

**🧪 [Projeto Qualidade](https://github.com/GabrielRenat0/Projeto-Qualidade-)** · Python · pytest · Jenkins · Docker Compose
Team project at Inatel: a 20-case automated test suite for a REST API (positive, negative and edge cases) with a documented test plan. I set up the Jenkins job as code and its Docker Compose service: each build runs the tests behind a 90% coverage gate, packages a versioned build, publishes the reports through Nginx and e-mails the result.

**🃏 [Pokecards Trading API](https://github.com/C14-INATEL/pokecards-trading-api)** · NestJS · Prisma · PostgreSQL · Jest · Docker · CircleCI
REST API for wishlists, trade listings and proposals, built by a team of 4 and auto-deployed to Render. I built the trade-proposal module with **TDD** (CRUD and an accept flow that closes the trade and cancels the other pending proposals, 29 unit tests) and owned the test-and-coverage job of the CircleCI pipeline.

**🔁 [Sistema de Trocas](https://github.com/Inatel-S03-20261/Tema-03-Sistema-de-Trocas)** · NestJS · Prisma · PostgreSQL · RabbitMQ · Docker
The next version of Pokecards, rebuilt around design patterns: State, Strategy, Factory Method and Adapter, plus trade-completed events published to RabbitMQ. I applied the **State Pattern** to trade proposals, so invalid status transitions are blocked in one place instead of conditionals spread across the service.
